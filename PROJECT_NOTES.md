# AutumNation Project Notes

## Current snapshot

This workspace contains **AutumNation** (code and saves still say Leaf Yard in places), a cozy autumn incremental game, ready to publish as a static site with GitHub Pages and installable as an app.

The game is a browser-only canvas experience. One robot gathers falling leaves into a bin; a truck sells the collected resources; upgrades expand the yard operation into additional robots and metal mining. The UI displays the resource and cash totals with upgrade cards rendered by the game logic.

**Single-file snapshots are retired.** The `AutumNationV*.html` files (one HTML file with the CSS and JS inlined) were how versions got passed around before the game was published from `public/` with GitHub Pages. They no longer need updating: `AutumNationV15.html` (V9) is the last one, and the live game is whatever is in `public/`. Don't make new ones unless asked. The old ones can stay as history or be deleted.

**Balance:** `BALANCE.md` is the reference for tuning and for pricing new things: the goals (including the 5-minute payback rule), the formulas, how to measure with the headless tools in `tools/balance/`, the current numbers, and pitfalls. Read it before any balance change and update its section 5 after one.

## Project layout

- `public/index.html` provides the page shell and HUD elements.
- `public/style.css` styles the interface.
- `public/audio.js` synthesizes all sound with Web Audio and exposes `window.LeafSound`; `game.js` only calls it (see the sound glue section).
- `public/game.js` contains the canvas scene, game loop, economy, upgrades, truck, save handling, and rendering.
- `server.js` is a zero-dependency Node development server with live reload for files under `public/`.
- `serve.ps1` is a Windows PowerShell fallback server without live reload.
- `start.bat` launches the Node server when Node.js is installed, otherwise it uses the PowerShell server.

There is no frontend build step or package installation requirement in the current setup.

## Run locally

From this folder, run `npm start` or `node server.js --no-open`. The default address is `http://localhost:8080`; if that port is already in use, the Node server tries the next available port up to 8099. The server prints the selected address. `start.bat` also opens the game in a browser.

Useful development URL options:

- `/?fresh` starts a new game state without replacing the saved game.
- `/?speed=4` runs the game at four times normal speed (the supported range is 0.25× to 20×).
- Combine them as `/?fresh&speed=10`.

Progress is stored in browser `localStorage` under `leaf-yard-save-v2` (v1 saves are not carried over). Tapping the cash counter 3 times within 2 seconds starts the test-money ladder ($100, $200, $500, $500, $1,000, $10,000, then $100,000 per tap). The Workshop card provides a Start over control.

## Git workflow (who commits, who pushes)

- **Claude** (Cowork / Claude Code) runs in a sandbox that cannot reach the user's Git credentials, so it **commits to `main` locally but does not push**. After committing, it tells the user what was committed and that `git push` is waiting. This is a Claude-specific limit, not a project rule.
- **Git locks are not Claude's responsibility.** If a Git lock prevents staging or committing, continue the requested code changes and checks where possible, leave the files intact, and briefly report that the commit needs GPT/Codex or the user to finish. Do not spend time repeatedly retrying Git commands or deleting lock files; another process may be using them. GPT/Codex or the user can resolve the lock, commit any remaining changes, push, and verify deployment.
- **Leave Git lock files alone.** Commits made from Cowork often leave `.git/HEAD.lock`, `.git/index.lock` or `tmp_obj` files behind (the connected folder can't delete files). Don't move, rename or delete them, don't ask for delete permission for them, and don't mention them to the user; they are handled outside Claude. Just commit and report the commit.
- **The user** pushes from their own terminal, where their GitHub credentials live. Pushing `main` triggers the GitHub Pages deploy.
- **GPT via Codex** runs with the user's credentials, so it **can and should commit and push** to `main` itself, so the site updates without a manual step.

## Game systems (v2)

- **Land:** three sizes in `AREAS` (Cottage plot, Meadow, Old orchard). Since V5 they cost $110 and $3,200 (were $25 and $700), so the small plot lasts longer. V5.1 lowered leaf fall a little (spawn 1.0 / 2.8 / 5.6 a second, caps 64 / 220 / 380) so the helpers pay off sooner. The camera starts zoomed in on the small fenced plot and zooms out when land is bought. A For Sale sign appears inside the top fence once cash reaches 50% of the next plot's price. Land beyond the fence is drawn darker and overgrown. The cottage plot has two small trees of its own (middle and bottom-right corner, flagged with `fam` in `TREES`) and two bushes (`BUSHES`, drawn live from `bushCvs` so they can shake).
- **Metal (V5: a later, bigger step):** one vein near the bin in the starting plot (moved to 128, -118 to make room for the corner tree), one fairly close and one far away in the Meadow, two far away in the Orchard (`SPOTS`). The metal slot costs $320 and every miner $120 (were $40 and $30); metal starts at $4 a chunk (was $1.20) and "Grade the metal" starts at $40. Drill, magnet, Diamond bit, Horseshoe, Electromagnet, Cutting oil and Lucky horseshoe all cost roughly 3–4× what they did. The metal tub has its own size track (`UP.metalBin`: 8 → 135 metal, $45 to $5,000) instead of being 40% of the leaf bin; old saves get the closest tub size (`flags.metalTub`). Each miner needs its own robot.
- **Robots:** up to twelve since V6.1 (ten in V6, six in V5.3), each with its own look (`STYLES`: Tinker is dusty, Pip slim, Clunk chunky, Rivet patched, Juniper round, Sterling polished chrome with a monocle) and its own upgrade levels. Each robot can be set to focus on leaves or mining (available once the metal slot is bought). A mining robot with no free miner gathers leaves and takes the next miner that frees up or gets built.
- **Unlocking tiers (V5.2):** research is no longer a list in the Workshop. On a robot's card, a track whose levels are used up shows its next unlock as a separate pill button next to the level dots ("Unlock 4 more · $3", `nextUnlock`, `.unlock` in the CSS), away from the buy buttons so repeated clicking can't buy it by accident. One purchase unlocks the tier for every robot that has the track. Claw and Reach rows appear (locked) as soon as their unlock is in sight (`rowShown`). The Workshop now only builds robots and sells yard-wide upgrades. Regular robot cards are two columns (Wheels, Basket, Pickup | Claw, Reach, Drill, Magnet); on phones they stack.
- **Per-robot tracks (`TRACKS`):** Wheels (speed), Basket (carry, also sets metal carry), Pickup (how fast the arm grabs), Claw (leaves per grab), Reach, Drill. Wheels, Basket and Pickup have 3 basic levels; every further generation is unlocked once (`TECH`, from the robot card since V5.2) and then bought per robot. Claw and Reach are different: one unlock each (Claw rake $6, Telescoping arm $7), then 5 levels with steep jumps, small first and big last (claw 2/3/5/8/12 leaves for $3/9/28/62/125; reach 30/44/64/92/125 for $2.50/8/24/55/111). The old Leaf vacuum and Long boom research is gone; unlock plus the 5 levels costs about what the old two unlocks plus 8 levels did. Old saves are moved to the closest new level (`flags.tiers5`). A level another robot already has costs 50% (`DISCOUNT`).
- **Shared upgrades (`UP`):** bin size, leaf price, metal tub, metal price, truck schedule, cleanup program. Since V4 the bin starts at 15 leaves and has 8 sizes with fixed prices in `UP.bin.costs`/`vals`: 22, 32, 48 leaves are cheap ($0.40, $0.80, $1.50), then $4 → 72, $15 → 110, and since V5.2 the last three are much bigger: $60 → 180, $190 → 320, $520 → 600. Since V6 "Sort leaves" has only 5 steps ($0.10 → $0.25 a leaf, about $15); the bagging table takes over after that (see V6). Truck pickups (`UP.truck`) are deliberately dear (base $1.25, ×2.3 per level), because more pickups make bin size matter less.
- **Cleanup program (V5.1, `UP.cleanup`, on the pickup sign):** three one-off deals with the truck that pay a lump sum for every 100 leaves it takes (`S.cleanN` counts toward the next 100): Join the cleanup program $20 → $15 per 100, Town cleanup contract $420 → $35, County compost deal $2,900 → $58. With Sort & bag maxed that brings a leaf to about $1.20, for about the same total cost as the old 12-step Sort & bag. The bonus pops up at payout ("+$15 cleanup bonus!"), the truck wears a small green badge with the tier number, and the sign card shows how many leaves until the next bonus. Not affected by the Market stall.
- **Upgrade all robots (V4):** with two or more robots, every track row on a robot card gets a green button (`allPlan`, buy id `rall`). If the robots are on different levels it reads "Match all" and brings everyone up to the best robot's level, every level at the copied-level price. Once they match it reads "All +1": one robot pays full price, the rest pay the copied-level price (`discFor`). It only works when you can pay the whole amount.
- **Magnet track (V4):** a seventh per-robot track. Each finished chunk of metal has a `doubleChance` of coming out as two. Fridge magnet (3 levels, needs the metal slot), then workshop research `horseshoe` ($70, needs a miner) and `electro` ($320) for 4 more levels each, up to 72%.
- **Yard-wide upgrades (`GEN`, V4):** the right-hand column of the Workshop card, which becomes two columns once you first hold $10 (`GEN_UNLOCK`, sticky via `flags.general`). Cheapest is $20. Mixed on purpose: some are plain boosts (`oil` +20% speed per level, `cutting` faster drills, `market` +10% sale price, `charm` +8% double metal), some change rules (`basket` makes copied basket levels cost 10% instead of 50%, `blueprint` makes every copied level cost 30%, `fingers` widens the claw). `servo` (Oil the servos) and `bulk` (Bulk robot parts) are commented out in `GEN` to keep the list short; while parked, `gl()` reports 0 for them so old saves lose the effect too.
- **Helper robots (V5): blowers and shakers.** Up to three of each (`HELPER_MAX`), built in the Workshop once you have held a quarter of the price (`helperShown`). Prices climb per unit: blowers $9 / $120 / $650 (`BLOWER_COST`), shakers $12 / $150 / $750 (`SHAKER_COST`). Their settings live in `S.blowers` / `S.shakers` (`{ lv }`), the runtime objects in `HB` (not `H`, which is the canvas height). They are drawn as yard robots in the same style as the others (treads, painted body with a band, amber eye, antenna), each a little different (`BLOWER_STYLES`, `SHAKER_STYLES`): blowers are low, wide, robot-vacuum-like bots with a ribbed hose trunk and hinged flaps on the head; shakers are squat front-facing bots with eye lenses on stalks and two oversized metal grabber claws (Snip has one huge one).
  - Wheels are shared by every kind of robot (`peersFor('speed')`): a level any robot already has costs the copied price, and the green Match all / All +1 button covers every robot of every kind. Each helper also has its own track: `blow` (Desk fan → Leaf turbine → Jet nozzle) and `shake` (Gentle wiggle → Hydraulic pincers → Rumble claws), with Workshop research `turbine`/`jet` and `pincers`/`rumble` (`needsKind`). Grease every axle speeds helpers up too.
  - **Blowers (V5.1: roomba laps)** drive laps around the outside of your land in a ∩ (up one side, across the top, down the other; `lapGeo`), blowing toward `BIN_MOUTH` (just above the bin) the whole way, and nudging leaves right beside them as well (`blowLeaves`). They face the bin and reverse when they have to. Each lap turns round and runs one `lapStep` further in, so leaves are herded inward; laps whose band holds fewer than 2 leaves are skipped (`lapLeaves`), and after the innermost lap they start outside again. Several blowers avoid sharing a lap. Since V5.2 a blown leaf keeps skimming toward the bin at an even pace after the blower drives on (`glideV`, `glideD`: about 58 units at the start, about 190 at full power), then settles; hitting a bush, trunk or the shed ends its glide. Blow power scales range (40 + 16×power), push and glide distance, and widens the lap step. Headless test, two Meadow robots: +37% with a starting blower, +44% at blow level 6, +63% fully upgraded. The air is drawn as faint curling wind lines and a few grass specks (`air`/`speck` particles). 
  - **Shakers** (`shakerDecide`, `shakeDrop`) go to the trunk of a tree on your land or to one of your bushes and shake it: a tree drops `shake` leaves (6 → 38 since V5.1; upgrades and research are about 20% cheaper), a bush 45% of that. Every tree and bush then has a hidden cooldown (`SHAKE_COOLDOWN`, `shakeCD`; 15 s since V5.2). They stop while the ground already holds 1.6× the plot's leaf cap. In the small plot, where leaves run out, one shaker added about 55% for two upgraded robots.
- **Text (V5):** "for every robot" is gone from everything except Rubber treads; the Workshop header is just "Yard-wide upgrades". The little tool box on the workshop is gone.
- **Hidden until affordable-ish (V4):** `S.peak` is the most cash you've ever held. Tier unlocks stay hidden until `peak` reaches 25% of their price (`seenPrice`), except the first three (`ALWAYS_SHOWN`: treads, hamper, servos); building a robot always shows. The same rule hides yard-wide upgrades and the bin's metal slot (shown from $10). Levels are saved in `S.gen`.
- **Multi-pickup (V4):** with a claw, `pickTarget` plans a patch: a seed leaf plus its nearest neighbours that all fit within `clawSpread` of the patch's centre, scored by walk distance minus a bonus per extra leaf. All planned leaves are claimed (`r.plan`). The hand goes to the middle of the patch (it must be within reach) and `aimClaw` tops the plan up with any free leaf the fingers can reach, then draws one finger out to each leaf. `clawSpread` = (12 + 5 × claw size) × the `fingers` bonus.
- **Tree drops (V4):** every 75–150 s (`dropT`) one tree whose lower canopy edge lies over your land sheds a pile of 13–20% of the leaf cap in one shower (`treeDrop`), landing just below the canopy so the pile stays visible. `__leafYard.treeDrop()` forces one.

- **Trees and bushes (V4):** `buildCanopies` draws each tree's crown from scalloped, leaf-textured clumps on a dome lit from the top left, in its own colour family (`FOLIAGE`, `TREE_FAMS`), with a short trunk below; the tree sways from its trunk base. Wild-land shrubs use `drawBush`. Tree drops land around the trunk base.
- **Camera:** scroll or pinch to zoom, drag or WASD/arrow keys to pan, Home/0 or the round button to recenter. The ground texture is rebuilt shortly after the view stops moving. Since V4, `camBounds` keeps the view within a modest margin around your land (120 units + 5% of the plot), never lets the road fill more than about a fifth of the screen when zoomed in, and the zoom-out limit is 85% of the framed view.

(The sim buys the $20 cleanup program late because it isn't a milestone; a real player will usually take it around 15–20 minutes.) The start is deliberately slow: base speed 58, a 3-leaf basket and a 1.3s grab.

## Mobile and full screen (V5.1)

The canvas uses `touch-action: none` and the page blocks browser zoom (viewport `user-scalable=no`, Safari `gesture*` events), so one finger drags and two fingers pinch-zoom the yard; lifting one finger after a pinch carries on dragging. On screens narrower than 640 px the upgrade card docks to the bottom like a sheet (`placeCard`), max 62% of the height, and the yard is framed to the full width. Card text, buttons and the HUD are smaller below 640 px wide or 500 px tall (media queries at the end of `style.css`). The round button in the top right (`#fsBtn`, or the F key) toggles full screen; it is hidden where the browser has no full screen API (iPhone Safari).

## Sound (added for V3)

`public/audio.js` builds everything at runtime: rustle grains (noise with tiny click bursts, filtered), a looped wind bed that follows the game's `wind`, per-robot beep voices (`VOICES`, moods in `MOODS`), music-box chimes, a truck putter and horn, and a 3/4 waltz in F (`TUNE_A`, `TUNE_B`, `CHORDS`, `buildPlan`) that alternates with 20 to 50 seconds of silence. Mix levels live in `BUS_LEVEL`; leaves are deliberately the loudest layer. Ambient robot chatter is limited to one every 7 seconds at most (`gate('chatter', 7)`), plus a random mutter every 16 to 38 seconds from `ambientChatter` in `game.js`. Buying upgrades, research, land, miners and robots makes no sound (only a newly built robot beeps hello); the "Beeps & chimes" switch still covers chatter, the truck horn and payouts, and the For Sale chime. Nothing plays in `__leafYard.sim`. Prefs key: `leaf-yard-sound-v2` (V4: "Leaves & wind" is off by default; v1 prefs carry over with that layer switched off).

`AutumNationV3.html` is a single-file snapshot of `public/` with sound. `AutumNationV4.html` is the snapshot after the V4 changes (multi-pickup fix, tree drops, magnet track, yard-wide upgrades, camera limits, leaf rustle off by default). `AutumNationV5.html` (updated for V5.2) adds blowers and shakers, the cleanup program, mobile touch controls and a full screen button, the yard trees and bushes, later and dearer metal with its own tub, and pricier land. Blowers and shakers have their own beep voices (`VOICES` 5 and 6 in `audio.js`).

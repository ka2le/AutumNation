# Balance work

For economy, progression, goals, simulated players, or balance tests, follow the
standing testing standard in [BALANCE.md](BALANCE.md) and the runner instructions
in [tools/balance/README.md](tools/balance/README.md).

Use the current completion-focused player as the main benchmark. Keep strong
specialization and source-skipping challengers: do not force the tester to buy a
desired mix. The target is useful mixed development across phases, with no source
made irrelevant and no consistently dominant shortcut that ignores the others.
Distinguish paid progression from fully upgraded capacity fixtures. Historical
balance concerns must be rechecked against current game code and capable players.
